# Resume‑Screening‑App
Resume Screening App With Python and Data Mining Techniques

## 🔍 Project Overview
This project automates the process of screening resumes using **Python**, **Data Mining**, and **Machine Learning**. It takes a collection of resumes, preprocesses the text data, and classifies them into relevant job categories to support HR and recruitment teams.

## 🧠 Features
- Preprocessing of resumes (cleaning and text normalisation)
- TF-IDF-based text vectorisation
- Machine learning model to classify resumes
- Simple web interface (if applicable)
- Stores results and screening outcomes

## 🛠️ Tech Stack
- Python  
- pandas, numpy  
- scikit‑learn  
- NLTK / text processing libraries  
- Flask / Streamlit (if used for app UI)
